# 基金自算实时估值（MVP）

多用户网页工具：每个用户有自己的基金列表，盘中按基金最新披露的前十大重仓股实时涨跌，自算基金估值。

## 功能特色

- **TrueNAV 自研估值算法**（当前 TrueNAV 1.2）：按基金最新披露前十大重仓股 × 实时行情加权计算，不依赖第三方估值接口；未披露股票仓位按已披露持仓加权涨跌补齐（TrueNAV 1.1），不再默认不动；估值再经历史净值 β 校准（TrueNAV 1.2：近 60 日估算涨跌 vs 官方涨跌回归，修正经理调仓偏差），卡片标注可信度高/中/低（按近 60 日回测误差分档）。算法独立版本号迭代，页面「演变」页有三版本同窗回测可信度曲线（MAE 1.003% → 0.676% → 0.643%）
- **QDII 盘前/盘后估值**：美股持仓取盘前/盘后价单独成行，盘中估值只用常规时段价，口径分开不混算
- **多市场覆盖**：A股、港股、美股、日股、韩股、台股持仓全部计入估值与分时曲线，曲线按交易时段拼接（去掉午休与市场间空档），曲线末点与卡片估值同源同数
- **板块识别**：按持仓行业加权定主板块并显示板块涨跌（A股走东财 F10 行业，海外持仓走手工板块表）
- **特殊基金**：ETF 联接基金按跟踪指数估值；债券基金按十年国债 ETF 涨跌估算；香港互认基金（968/969xxx）可搜索添加并显示净值
- **排行榜**：涨幅榜（全市场及股票/混合/债券/指数/QDII/FOF 分类，7 个周期）、美股占比榜（QDII，美股权重占净值比例）、波动率榜（近1月/近3月/近6月/近1年四档年化波动率，从低到高，可按基金分类筛选）、收益波动比榜（区间涨幅 ÷ 波动率，四档窗口），每个榜单附用途解释；榜上基金可一键加入自选（默认未分类），且榜上基金数据由后台限速预热补全，加入自选后估值与可信度即时显示
- **多用户与管理**：账号密码登录、每人独立自选与分类；管理员可管理用户（在线状态、IP 归属地、邮箱、累计在线时长、登录次数、最近两次登录）、查看登录记录，信息有变化时行上有更新提示
- **邮箱验证（可选，默认关闭）**：默认用户名+密码注册；设置 `EMAIL_AUTH=1` 后启用邮箱验证码注册（6 位、10 分钟有效）、邮箱找回密码与老用户绑定邮箱，验证码有发送频率与尝试次数限制；SMTP 未调通时保持默认关闭即可，不影响客户注册
- **系统备份与恢复**（管理员）：每天 0 点自动备份、保留 10 份，备份文件 gzip 压缩，可手动备份、下载、恢复；恢复时自动迁移，老版本备份可恢复到新系统
- **数据接口与数据流监控**（管理员）：管理页「数据接口」子页按数据类型（净值/持仓/仓位/分时/行情/日线/搜索/排行榜/行业等）分组卡片列出系统全部上游接口（东财/新浪/Yahoo/腾讯/同花顺等）的用途、主源/兜底定位与最近一次调取状态，每组标注有无兜底；所有关键数据路径被限流或阻断时，页面底部自动显示「数据流异常，修复中」，恢复后自动消失
- **多源兜底**：东财为主源，新浪/Yahoo/腾讯/同花顺官方接口（fuyao，需配置 `FUYAO_API_KEY`）作兜底——东财净值/持仓/股票仓位失败时自动切同花顺，东财分时双主机被限流时自动切 Yahoo/腾讯；v1.4.8 起同花顺再补 A股日线（东财日线失败时）、A股实时行情（新浪失败时）与基金行业配置（F10 行业失败时，仅显示行业与占比）；港美股日线/行情、基金搜索已补兜底（见 v1.6.0），排行榜加页级容错、仍无独立第二数据源（数据接口页标注「无兜底·待补」）。单一数据源被限流不影响页面出数
- **秒开体验**：服务端缓存 + 后台预热（行情、曲线、榜单、估值），页面先出缓存再更新，增删基金即时生效
- **手机适配**：单文件前端、无构建，360px 窄屏不撑破，基金名完整显示
- **单个基金详情页**：点基金卡片进入，顶部显示当日涨幅（自算估值）、近1年涨幅与持有人数（库内排名）；「业绩走势」页签画本基金净值曲线 vs 沪深300（近1月/3月/6月/1年/3年切换，下方附净值表：日期/净值/日涨幅）；「关联板块」页签显示基金当日估值走势（分时曲线），可一键分享成图片（PNG 下载或系统分享）；行业分布条形图（持仓行业占净值比例与涨跌）。持有人数取自同花顺持有人接口（7 天缓存），排名只在本站基金库（自选 + 排行榜基金）内排，基金库越大排名越接近全市场；不做社交、持仓表与成本收益
- **板块资金流榜**：排行榜新增一榜，行业板块按今日主力净流入（超大单+大单主动性净额，亿元）从高到低取前 50，每 60 秒更新；数据走东财板块资金流接口（同花顺资金流接口仅限 AI 客户端，不可用）

## 架构

- 后端：Python 3 + FastAPI + uvicorn（单进程，监听 127.0.0.1:8000）
- 数据库：SQLite（WAL），存用户、会话、自选列表、持仓缓存、净值缓存
- 前端：单文件 HTML + 原生 JS，FastAPI 直接托管，无构建步骤，手机/电脑自适应
- 缓存：股票行情内存缓存 45 秒（全站共用，一次批量请求）；净值缓存 1 小时；持仓缓存 24 小时；上游失败时返回上次缓存并标记 stale

## 数据源（2026-11-19 实测可用）

| 用途 | 接口 | 备注 |
|---|---|---|
| 基金搜索 | fundsuggest.eastmoney.com/FundSearchAPI.ashx | 需 User-Agent |
| 官方净值 | api.fund.eastmoney.com/f10/lsjz | 需 User-Agent + Referer（jjjz_{code}.html） |
| 前十大持仓 | fundf10.eastmoney.com/FundArchivesDatas.aspx?type=jjcc | 返回 HTML 表格，需解析；含报告期和截止日期 |
| 股票实时行情 | hq.sinajs.cn/list= | 需 Referer: finance.sina.com.cn，GBK 编码，支持批量 |

新浪行情字段（实测）：
- A 股（sh/sz）：0=名称，2=昨收，3=现价，30=日期，31=时间
- 港股（hk）：0=英文名，1=中文名，3=昨收，6=现价，17=日期，18=时间
- 美股（gb_）：0=名称，1=现价，2=涨跌幅%，3=北京时间，26=昨收

股票代码映射：6 位且 6/9 开头 → sh；6 位其他 → sz；5 位数字 → hk；字母代码（美股）→ gb_ + 小写代码（如 NVDA → gb_nvda）。行情时间取全部持仓中最新的一条（QDII 基金在美股时段显示美股实时时间）。

## 估值方法

- 估算涨跌幅 = Σ（重仓股占净值比例 × 该股今日涨跌幅）/ 100 + 未披露股票仓位 × 已披露持仓加权平均涨跌幅 / 100（未披露股票仓位 = 最新季报股票仓位 − 前十大覆盖，取不到仓位时为 0）
- 自算估值 = 最新官方单位净值 ×（1 + 估算涨跌幅 / 100）
- 每条估值同时展示：市场/板块占比（占净值比例，含未披露部分）、持仓报告期、行情时间

局限：只披露前十大（通常覆盖约一半仓位），持仓为季报数据、基金经理调仓后会偏；未披露部分按已披露持仓平均涨跌近似，债券/现金部分按 0 涨跌；港股按港币行情直接计算（未计汇率变动）。回测基线见 backtest-report.md（tools/backtest.py）。页面标注：自算估值，仅供参考，以基金公司公布净值为准。

## 本地运行

```bash
cd fund-valuation
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
./venv/bin/uvicorn app:app --host 127.0.0.1 --port 8000
```

## 安装（VPS，Debian 13）

```bash
git clone https://github.com/Tao314/fund-valuation.git /opt/fund-valuation
cd /opt/fund-valuation
sudo bash install.sh
curl -s http://127.0.0.1:8000/api/me   # 应返回 {"detail":"未登录"}
```

install.sh 会做：装 python3/venv、建虚拟环境装依赖、写 systemd 服务 `fund-valuation`（监听 127.0.0.1:8000）并启动。脚本可重复执行（幂等）。

服务只监听 127.0.0.1:8000。对外访问请在前面加 Nginx 或 Caddy 反代并配 HTTPS，例如 Caddyfile：

```
your.domain {
    reverse_proxy 127.0.0.1:8000
}
```

更新到新版：

```bash
cd /opt/fund-valuation
git pull
systemctl restart fund-valuation
```

常用运维命令：

```bash
systemctl status fund-valuation        # 看状态
journalctl -u fund-valuation -n 30 -l  # 看日志
```

备份只需复制 `fund.db` 文件。

## 卸载

```bash
systemctl disable --now fund-valuation
rm -f /etc/systemd/system/fund-valuation.service
systemctl daemon-reload
rm -rf /opt/fund-valuation
```

删完即干净。install.sh 装的 python3、python3-venv 等系统包可保留，不影响其他服务；反代（Nginx/Caddy）里的站点配置需自行删除。

## 备份与恢复

- 备份存放在数据库同目录的 `backups/` 下（`fund-backup-YYYYMMDD-HHMMSS.db.gz` + 同名 `.json` 元信息），为 SQLite 在线一致性拷贝（backup API，WAL 安全）后 gzip 压缩，节省空间。v1.4.0 之前的未压缩 `.db` 旧备份仍可列出、下载与恢复。
- 每天 0 点（Asia/Shanghai）自动备份；启动时若无任何备份会先补一份。自动、手动、恢复前备份合计保留最近 10 份，超出自动删除。
- 仅管理员可用（管理页「系统备份」）：立即备份、下载任意备份、恢复备份。恢复前会自动备份当前数据；恢复后自动执行全部数据库迁移（建表 + 加列），旧版本备份可直接恢复到新系统，版本不一致不阻断恢复。
- 恢复后会话以恢复后的数据库为准，当前会话不在其中时需重新登录。

| POST | /api/admin/backups | 立即手动备份（仅管理员） |

排序规则：先按分类顺序（user_categories 表，未分类永远最后），分类内按基金 sort_order。调基金顺序只在所属分类内生效，不动分类顺序；调分类顺序整组移动，组内基金顺序不变。

页面分两个视图（顶部「估值」/「设置」切换）：
- 估值页：只看估值表格（按分类分组、组标题只有分类名）、刷新按钮、自动刷新倒计时和更新标记说明，没有管理控件。
- 设置页：自动刷新间隔（10-600 秒，保存后立即生效）、分类管理（新增/重命名/删除/↑↓ 排序）、自选基金（搜索添加、设分类、组内 ↑↓、删除）、账户（修改密码）。

自动刷新间隔按用户存数据库（users.refresh_seconds，默认 60），倒计时跟随该值；本次刷新有变化的基金行黄底高亮并带「更新」标记，无变化时标记自动消失。

所有自选列表操作都按会话中的 user_id 过滤，不信任前端传入的用户 ID。

## 部署配置（邮箱验证码，可选，默认关闭）

邮箱验证码功能由 `EMAIL_AUTH` 开关控制，**默认关闭**（用户名+密码注册，页面不显示邮箱相关入口，邮箱接口返回 404）。确认 SMTP 可用后再设 `EMAIL_AUTH=1` 开启。开启后注册/找回密码的验证码邮件走 SMTP，配置只从环境变量读取（不写进代码仓库）。未配置 `SMTP_HOST` 时进入日志模式：验证码只写服务日志（`[email-code] to=... code=...`），便于本地测试；正式部署请配齐以下变量后重启服务：

| 变量 | 说明 |
|---|---|
| `EMAIL_AUTH` | 邮箱验证开关：`1`=开启（邮箱验证码注册/找回/绑定），缺省或 `0`=关闭（用户名+密码注册） |
| `SMTP_HOST` | SMTP 服务器地址，如 `smtp.example.com` |
| `SMTP_PORT` | 端口，默认 465 |
| `SMTP_USER` | SMTP 登录账号 |
| `SMTP_PASS` | SMTP 登录密码/授权码 |
| `SMTP_FROM` | 发件人地址（缺省同 `SMTP_USER`） |
| `SMTP_SSL` | `1`=SSL 直连（465），`0`=STARTTLS（587）；未设置时按端口推断 |
| `FUYAO_API_KEY` | 同花顺 fuyao 官方接口 Key（可选）：配置后东财净值/持仓/股票仓位/A股日线、A股行情、行业配置失败时自动走同花顺兜底；未配置则兜底禁用，不影响其他功能 |

systemd 示例（在服务单元的 `[Service]` 段加入，或用 `EnvironmentFile` 指向仅 root 可读的 env 文件）：

```ini
Environment=SMTP_HOST=smtp.example.com
Environment=SMTP_PORT=465
Environment=SMTP_USER=noreply@example.com
Environment=SMTP_PASS=********
Environment=SMTP_FROM=noreply@example.com
```

同花顺兜底（可选）：在同一服务单元 `[Service]` 段加一行 `Environment=FUYAO_API_KEY=********`（或写入 `EnvironmentFile` 指向的仅 root 可读 env 文件），重启后生效；管理页「数据接口」中同花顺六项状态由「未配置」变为可调取即配置成功。

改完 `systemctl daemon-reload && systemctl restart fund-valuation` 生效。验证码规则：6 位数字、10 分钟有效、同邮箱同用途 60 秒内只能发一次、每天最多 10 次、输错 5 次作废。

开启 `EMAIL_AUTH=1` 前，先单独测发信（不依赖网页）：

```bash
cd /opt/fund-valuation
python3 tools/smtp_test.py 你的收件邮箱@example.com
```

脚本从环境变量读 SMTP 配置；环境变量里没有 `SMTP_HOST` 时自动读 `/etc/systemd/system/fund-valuation.service.d/smtp.conf`。它逐步打印连接/登录/发送结果，失败时打印异常类型与信息（不打印密码）；`--verbose` 会打开 SMTP 调试输出（内含编码后的凭据，切勿粘贴外发）。测通后再把 `EMAIL_AUTH=1` 加到服务环境变量并重启。
